# GPS Alarm — Web

An alarm that rings when you reach a place, not a time — set a destination, doze off on the train, get woken at your stop.

This is the web side of GPS Alarm: the public support page and the privacy policy, served by
GitHub Pages at https://graboosky.github.io/gps-alarm-web/. Plain HTML and CSS, no build.

Conventions, structure and the release rules live in the container — see `../CLAUDE.md` and
this repository's `CLAUDE.md`.
